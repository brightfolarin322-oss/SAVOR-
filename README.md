# 🍽️ SAVOR — Restaurant Website

A modern, elegant, and responsive restaurant website designed for a premium dining experience.

## 🌐 Live Website

👉 https://brightfolarin322-oss.github.io/SAVOR/

## ✨ Features

- Responsive design for mobile, tablet, and desktop
- Modern restaurant landing page
- Hero section with call-to-action
- Food and menu showcase
- Restaurant story section
- Chef section
- Image gallery
- Smooth navigation
- Interactive website elements
- Clean and reusable CSS structure
- Optimized image organization

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
